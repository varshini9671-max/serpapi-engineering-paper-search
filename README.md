# SerpApi Engineering Paper Search

An engineering research paper search application built using SerpApi.

## Features

- Search for relevant engineering research papers
- Display paper titles and authors
- Find DOI links for research papers
- Simple and user-friendly interface

## Technologies Used

- Python
- Streamlit
- SerpApi API

## How to Run

1. Install the required Python packages.
2. Add the SerpApi API key.
3. Run the Streamlit application.

## Project Purpose

This project helps engineering students and researchers quickly find relevant research papers, authors, and DOI links.
